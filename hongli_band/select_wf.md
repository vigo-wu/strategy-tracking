# 滚动选股验收：使用说明

用 **已有 local_bt 分年明细** 做滚动选股，再和现行跟踪池做 **组合回放过门**。过门才允许把按年篮子当草稿；默认 **不改** `config.py`、**不 deploy**。

全窗口打分表、侧栏 Top N、`BOOK_STOCKS` 代码草稿属于 **研究台**，不是选股结论。结论只看页面上的 `PASS` / `KEEP_CURRENT` / `FAIL`。

本地回测怎么跑、CSV 从哪来：见 [`local_bt.md`](./local_bt.md)。参数网格（止损/TRAIL 等）是另一条路，不要和选股嵌套扫。

## 它解决什么

跟踪池很小。如果用 2018–2026 全窗口打分再 Top N，等于用验收年选股，回测几乎一定好看。本流程强制：

- 每年持有的篮子，只能用 **该年之前** 的分年 KPI 打分。
- 和现行 `BOOK_STOCKS` 比的是 **组合盈亏**（资金帽 + `BOOK_LOT_MAX`），不是选股「得分」、也不是单票 10 万相加。
- 硬门关复利：每年独立空仓，避免训练窗盈亏滚进验收期本金。

扫描宇宙是已经跑过 local_bt 的票（幸存者），**不是全 A 股**。没有 ST 字段，资格里也不造 ST 名单。

## 开始之前

1. 安装依赖（与本地回测相同）：

   ```bash
   pip install -r hongli_band/scripts/local_bt/requirements.txt
   ```

2. 日线在 `tools/csv/`。资格读 **复权子目录**（优先 `none/`），不要指望根目录扁平 CSV。上市日来自日线第一根有效 K。

3. `hongli_band/report/<复权>/` 里要有 **按自然年分段** 的操作明细（建议同时有 SMA/EMA 对照）。没有分年文件，打分年会空，闸门直接 `FAIL`。

4. 现行对比池来自 [`scripts/qmt/hlband/config.py`](./scripts/qmt/hlband/config.py) 的 `BOOK_STOCKS`。

## 启动

仓库根目录：

```bash
python hongli_band/local_bt_ui.py
```

浏览器顶栏选 **选股方案**。页面从上到下是：

1. **滚动验收**（结论区）
2. **研究台**（打分表 / Top N / 折叠草稿）

侧栏「打分年份 + 硬过滤」只服务研究台。**验收按钮不用侧栏阈值。**

## 年窗（界面锁死，不要手改验收年）

与网格共用 `year_start/end`、`check_*`（默认 2018–2026 / 验收 2023–2026）。选股另外把 **2022 划成预验收**，文案是「选股训练窗 / 预验收 / 验收期」，不要和网格结论表的「调参期」混为一谈。

| 角色 | 持有年 | 打分用哪些年 | 允许做什么 |
| :--- | :--- | :--- | :--- |
| 打分样本 | 不持有 | 2018–2020 | 只给后面持有年当历史 KPI |
| 选股训练窗 | **2021**（回看 3 年后才开始持有） | 2018–2020 | 过滤实验室预选；过门要与验收期同向 |
| 预验收 | **2022** | ≤2021 | 规则冻结后只看一次，不得反号、不得显著更差 |
| 真验收 | **2023–2026** | 各年只用该年之前 | 只回放、只过门，禁止再改 N / 过滤 |

最短回看 `lookback=3`：`year_start=2018` 时第一段持有年是 2021。2018 年不能打分（没有更早的 KPI），空窗禁止回落全历史。

训练窗持有年实际 **只有 2021 一年**，同向门样本很短。这是设计，不是漏年。

## 日常怎么点

### 1. 只想知道「该不该换池」

点 **滚动验收（命名格 base）**。

用冻结命名格 `base`：按打分窗年数缩放最少轮次（每窗年 ×2），**忽略**你刚拧的侧栏过滤。每年独立空仓组合回放，可能要几分钟（会读日线 meta、按年回放篮子）。进度条为整次点击的总进度（`总进度 12/40`），并显示当前步骤（读上市日 / 按年打分 / 自动篮或现行池 · 持有年 · 缓存或回测）。换路径时进度条不会跳回 0。

看三条 Δ（自动篮 − 现行池，单位元）：

- 训练窗 Δ
- 预验收 Δ
- 验收期 Δ（主依据）

以及各持有年 **资格只数**。全是 0 说明上市日/成交额分位把宇宙清空了，先查 CSV，不要换池。

### 2. 想在 ≤8 组过滤里预选一组

点 **过滤实验室（训练窗预选 + 预验收确认）**。

只跑到预验收年（含 2022），用训练窗 Δ 预选、2022 确认未反号，冻结一组后再跑完整验收。实验室本身 **不写** `picks.json`。

命名格（`select_config.named_filter_cells`，含 `base`，最多 8）：

| id | 含义 |
| :--- | :--- |
| `base` | 缩放轮次（每窗年 ×2） |
| `per_year2` | 每年至少 2 轮 |
| `pos60` / `pos70` | 盈利年占比 0.60 / 0.70 |
| `top5` / `top7` | Top 5 / Top 7 |
| `traded70` | 成交年占比 0.70 |
| `vol20` | 剔除最高波动 20% |

没有一组训练窗优于现行，则冻结 `base`。不要为了过门再手工加第 9 格，也不要在验收期上继续拧过滤。

## 资格（进打分宇宙）

在扫描到的 local_bt 宇宙内，相对 **该段持有年**：

- 日线推出的上市年：上市满 **2** 年
- 该段 **打分窗** 内日均 `amount`：去掉最低 **20%** 分位（不用 2018–2026 一次算死）
- 无 ST

日线 meta 必须来自 `tools/csv/none/` 等复权子目录。根目录扫不到文件时会 `FAIL`：资格 0 只。

## 硬门（改判决）

硬门关复利。全过才可能 `PASS`：

1. 任一段打分年与持有年相交，或打分年空集 → `FAIL`
2. 资格全空（无上市日 / 分位清空）→ `FAIL`
3. 验收期组合回放失败 → `FAIL`
4. 验收期 `pnl(自动篮) ≤ pnl(现行池)` → `KEEP_CURRENT`
5. 训练窗 Δ 与验收期 Δ 反号 → `KEEP_CURRENT`
6. 预验收相对现行反号，或显著更差（劣于 `max(500, 0.2×|验收Δ|)`）→ `KEEP_CURRENT`

`FAIL`：隔离坏了或数据不可用，先修流程。`KEEP_CURRENT`：隔离通过但换池不值，继续用现行池。

`prev_hold`（用上一段篮子）默认 **不跑**，也不进硬门。

## 软预警（不改判决）

写在页面 caption / `select_gate.json` 的 `warnings`、`overfit`：

- 换手：相邻年 Jaccard &lt; 0.3，或一年换掉超过 3 只
- 单票：验收期篮子实质单票，或一只票贡献组合盈亏 ≥ **60%**
- DSR / PBO：要有足够组合 **日** 收益（默认至少 60 个日收益）才算；只有 4 个年点则 `skip`。PBO 还要试验列 ≥10，否则 `skip`。`overfit.passed=False` **不会**变成选股 `FAIL`

## 判决之后做什么

| 判决 | 页面 | 磁盘 | 你该做 |
| :--- | :--- | :--- | :--- |
| `PASS` | 展示按年 JSON | 写 `hongli_band/report/picks.json` 和 `select_gate.json` | 复制按年篮子做后续回放；**不要**把最后一年 Top N 写成静态 `BOOK_STOCKS` |
| `KEEP_CURRENT` | 不展示篮子 | 只更新 `select_gate.json`；若有旧 `picks.json` 会删掉 | 维持现行跟踪池 |
| `FAIL` | 同上 | 同上 | 按原因修数据或规则，不要换池 |

`picks.json` 顶层 key 是持有年，例如：

```json
{
  "2021": { "600000.SH": { "ma_type": "EMA", "dividend_type": "front_ratio" } },
  "2023": { "601988.SH": { "ma_type": "EMA", "dividend_type": "front_ratio" } }
}
```

滚动产物是这份按年映射。现行实盘仍是一份静态池。把最后一年 Top N 写进 config，等于放弃滚动，这次验收作废。要改跟踪池须自己编辑再 deploy，程序不会代写。

## 研究台（非结论）

侧栏起始年 / 结束年默认打到 **预验收前一年（2021）**。可以手动拉到 2026 看表，一旦包含验收年，页面会警告：表格与草稿都不是结论。

研究台会：

- 在侧栏窗口上重算建议均线 / 复权并打分
- 写出 `hongli_band/report/local_bt_stock_select.csv`
- 把 `BOOK_STOCKS` 草稿放在 **折叠区**，默认收起

改侧栏过滤立刻改研究台，**不会**改已经跑完的滚动验收结果。要点验收按钮才会重跑闸门。

## 和其它模式的区别

| | 滚动验收（本文） | 研究台（同页下方） | 数据分析 | 参数网格 |
| :--- | :--- | :--- | :--- | :--- |
| 目的 | 换不换池 | 观察全窗打分 | 手工篮子持有回放 | 止损/TRAIL 等命名格 |
| 谁选股 | 规则 + 时间锁 | 人看 Top N | 人指定 | 不选股（跟踪池锁死） |
| 过门 | 经济硬门 | 无 | 无 | 验收期 + 调参期同向 |
| 复利 | 硬门关闭 | — | 默认可开 | 分年独立账户 |
| 写 config | 否 | 否 | 否 | 否 |

建议顺序：先冻参数（网格过门或维持 `base`），再验收选股。不要选股过门后又自动开一轮参数网格。

## 产物路径

| 文件 | 何时写 |
| :--- | :--- |
| `hongli_band/report/select_gate.json` | 每次验收（含 FAIL / KEEP） |
| `hongli_band/report/picks.json` | 仅 `PASS` |
| `hongli_band/report/local_bt_stock_select.csv` | 研究台每次刷新打分 |
| `hongli_band/report/<复权>/local_bt_book_hold_*` | 组合回放缓存（文件名含篮子哈希，同篮可复用） |

侧栏「刷新缓存」清选股扫描缓存，不删这些回放文件。改了拼接脚本或仓位规则后，需要强制重跑相关年份（数据分析里有「强制重跑」；选股闸门当前按缓存命中，逻辑变了应清对应 hold 明细或换报告目录）。

## 明确不要做

- 把研究台 snippet 或非 `PASS` 的磁盘文件当结论
- 验收不过就放宽过滤直到过门
- 持有年里重选 SMA/EMA
- 用 DSR 否决已经 `KEEP_CURRENT` 的现行池
- 在验收期上继续调 Top N / 硬过滤
- 侧栏拧完过滤却以为验收用的是这套阈值
