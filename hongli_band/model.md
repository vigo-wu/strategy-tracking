# 红利板块波段策略：周线定方向，日线找买卖点

**主题目录**：`hongli_band/`｜**版本**：v1.2｜**运行**：国金 QMT 终端模型（见 §5）

---

## 核心逻辑
红利资产（如银行、煤炭、电力）具备高股息与稳健属性，其牛市多为“慢牛爬坡”，熊市多为“震荡抗跌”。
本策略的核心是：**在安全边际内，利用周线与日线的周期共振，做高胜率的顺势高抛低吸**。

行情一律使用 **前复权**（`dividend_type=front_ratio`）。

---

## 一、 周线看方向：确认红利板块的“免疫期”

周线级别决定了我们要不要参与红利板块。只有在周线趋势向上时，才能启动日线波段；周线空头则必须空仓。

### 1. 指标配置
* **均线**：5周、10周、30周（生命线）、60周均线（SMA）。
* **动量**：周线 MACD(12,26,9)。

### 2. 多头方向（可做多）— 脚本条件
同时满足：
1. `MA5_W > MA10_W`
2. 周 MACD：`DIF > 0` 且 `HIST > 0`（零轴上红柱）
3. `MA30_W` 走平或向上（相对前一周不低于约 -0.2%）

### 3. 空头方向（必须空仓）— 脚本条件
满足任一即空仓 / 禁止新开：
1. `Close_W < MA30_W`
2. 周 MACD 在零轴下方死叉：`DIF` 下穿 `DEA` 且 `DIF < 0` 且 `DEA < 0`

（文案中的“高位长上影 / 跷跷板”作人工观察，未写入自动条件。）

## 二、 日线找买卖点

主图周期为 **日线**；信号在日线收盘确认，**次日开盘**执行。

### 1. 买入：周线多头 + 下列任一低吸
* **买点①（缩量回踩）**：收盘靠近 `MA20` 或 `MA60`（默认容差 2.5%），且成交量 ≤ 20日均量 × 0.65
* **买点②（二次金叉）**：日线 MACD 的 `DIF/DEA` 均在零轴上方，且当日金叉（上穿）
* **买点③（指标超卖）**：前一日 `J < 0`，当日 `J` 拐头向上，且收阳线

风控：当日涨幅 ≥ `CHASE_MAX_PCT`（默认 5%）则跳过买入（绝不追高）。

### 2. 卖出：下列任一高抛 / 风控
* **卖点①（均线乖离）**：5日乖离率 `BIAS5 >= 6%`
* **卖点②（放量滞涨）**：创近 20 日新高 + 量 ≥ 均量 × 1.8 + 长上影或十字星
* **卖点③（动能背离）**：高位 MACD 死叉，或新高但红柱缩短
* **周线转空**：强制次日开盘清仓
* **硬止损**：相对成本下跌 ≥ 8%

## 三、 策略执行标准对照表

| 步骤 | 分析周期 | 核心观察指标 | 核心行动条件 |
| :--- | :--- | :--- | :--- |
| **定方向** | **周线** | 5/10/30周均线、周MACD | **多头**：MA5>MA10 + 零轴上红柱<br>**空头**：跌破30周线或零轴下死叉 → 空仓 |
| **找买点** | **日线** | 20/60日均线、日MACD、KDJ、成交量 | **买入**：周线多头 +（缩量回踩 **或** 零轴上金叉 **或** KDJ超卖拐头） |
| **找卖点** | **日线** | 5日乖离、K线形态、MACD | **卖出**：乖离过大 **或** 放量滞涨 **或** MACD死叉/背离 **或** 周线转空 |

---

## 四、 风控三大盲区

* **绝不追高**：日线大阳/追涨默认过滤（`CHASE_MAX_PCT`）。
* **股息率锚定**：人工参考；脚本未接入基本面股息率字段。
* **注意除权缺口**：脚本强制前复权拉数；主图查看也请用前复权。

## 五、 QMT 运行（国金终端模型交易）

**脚本**：[`scripts/qmt/qmt_terminal_hlband.py`](./scripts/qmt/qmt_terminal_hlband.py)  
**部署**：[`scripts/qmt/_deploy_qmt_gbk.py`](./scripts/qmt/_deploy_qmt_gbk.py) → GBK 写入 `HlBand.py` / `红利波段.py`  
**片段**：`scripts/qmt/hlband/`（单仓 + `qmt_common`）

| 配置项 | 默认 | 说明 |
| :--- | :--- | :--- |
| `DRY_RUN` | `True` | 只打印，不 `passorder`；仍模拟 T+1 |
| `PERIOD` | `1d` | **主图必须为日线** |
| `TRADE_BUDGET` | `50000` | 单笔买入预算（元） |
| `BIAS5_SELL` | `6.0` | 5日乖离率卖出阈值（%） |
| `STOP_LOSS` | `0.08` | 相对成本硬止损 |
| `STATE_FILE` | `...\python\hlband_qmt_state.json` | 实盘仓位；回测只用内存 |

**下单约定**

- 信号日收盘确认 → `pending_entry`[Hl[HlBand.py](../../../service/GJQMT/python/HlBand.py)Band.py](../../../service/GJQMT/python/HlBand.py) / `pending_exit` → **次日开盘**下单  
- `DRY_RUN`：不下单，日历日 T+1 模拟  
- 回测：可卖 = `bt_held - bt_locked`；`sell skip` 不清仓  
- 实盘：成交后才改仓；可卖 = `m_nCanUseVolume`

```bash
python hongli_band/scripts/qmt/_deploy_qmt_gbk.py
```

**操作步骤**

1. 打开国金 QMT，登录交易账号  
2. 行情主图打开红利标的（银行/煤炭/电力/红利ETF 等），周期选 **日线**，前复权  
3. 【模型交易】→ 选择 `HlBand` / `红利波段` → 选账号 → 先回测或模拟  
4. 日志确认 `HlBand v1.2 init`、`PERIOD= 1d`、`diag: d1_ok` / `w1_ok` 后，再改 `DRY_RUN=False` 并重新部署编译  
   成交后 `pe`/`px` 应回到 False；买卖笔数成对、期末空仓后再信盈亏  
   卖出行可见 `SELL by signal=... label=卖点x-...`（买入同理 `BUY by signal=`）
5. 真下单：模型交易选 **实盘** + `DRY_RUN=False`  
6. 遵守 A 股 T+1；日志出现 `sell skip T+1` 属正常  

只编辑仓库内 `hlband/*.py`；改完必须 re-deploy。勿手改 `qmt_terminal_hlband.py` 或国金 `python\` 下 GBK 文件。
