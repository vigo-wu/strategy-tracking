要解决不同红利标的对 SMA（简单移动平均线） 和 EMA（指数移动平均线） 的偏好差异，核心逻辑不能靠人工硬套，而是要通过算法实现“趋势跟踪偏好（EMA）”与“均线回踩偏好（SMA）”的自动化识别与适配。
在你的红利波段策略（v1.44）框架下，可以通过以下三种设计思路来实现两种均线的无缝适配与自动切换：
------------------------------
## 🔎 核心痛点：SMA 与 EMA 的股性错配

* EMA（重视近高权重）：对近期价格变化极灵敏。适合趋势强劲、阶梯式重心抬升、回调浅的标的。这类标的如果用 SMA，往往还没回踩到均线就又涨上去了（容易踏空）。
* SMA（全周期权重均等）：相对迟钝、走势平滑。适合股性死沉、反复拉锯、深度回踩、脉冲式上涨的传统大蓝筹。这类标的如果用 EMA，均线会跟着脉冲频繁变形，产生大量“假回踩”和“假跌破”噪声。

------------------------------
## 📊 方案一：基于“回踩有效性”的历史胜率回归（推荐：改动小、效果直接）
不预设哪只股票适合哪种均线，而是在每天/每周初始化时，让系统在历史数据中跑一个小型的“回踩去噪回测”，自动择优。
## 1. 算法识别逻辑

* 提取样本：获取该标的过去 1 年的日线历史数据。
* 模拟买点触发：分别用 SMA20 和 EMA20 配合你当前的缩量条件（vol < MAVOL10 × 0.9），找出历史上的所有“模拟低吸点”。
* 计算两组“回踩纯净度”：
* SMA 纯净度：股价触及 SMA20 容差范围内后，在未来 T+5 日内，收盘价不有效跌破硬止损线，且能够顺利反弹的“真低吸”比例。
    * EMA 纯净度：同上，看触及 EMA20 后的反弹真伪。
* 择优注入：哪条线在历史上的“触及-反弹”胜率更高、噪声（假信号）更少，系统就将该标的的 MA_TYPE 参数锁定为该均线类型。

------------------------------
## 📊 方案二：基于“趋势粘性”的斜率聚类（从股性本质切入）
通过量化股票走势是“平滑慢爬坡”还是“剧烈震荡台阶”，直接为标的画像。
## 1. 算法识别逻辑

* 计算指标：计算过去半年内，股价偏离均线距离的方差，或者周线 MACD 柱子（w_macd_golden 相关元数据）的变动频率。
* 股性画像分类：
* 高粘性/强趋势股（如部分电力、资源类红利）：股价长期贴着均线走，极少有深度砸盘。这类标的自动适配 EMA，利用其“高灵敏、快贴紧”的特性，在其稍有缩量回踩 EMA 时就敏锐加仓（pullback_vol）。
    * 低粘性/箱体震荡股（如部分传统大行、大市值基建）：平时一叶扁舟、死水微澜，偶尔来个大阳线或深度砸盘洗盘。这类标的自动适配 SMA，利用 SMA “不被短期脉冲带偏、坚守大箱体下沿”的迟钝性，死守强支撑（MA_TOUCH_TOL）。

------------------------------
## 📊 方案三：采用双均线“组合过滤器”（双线共振）
如果你不想让每只股票只选一条线，可以让策略同时计算 SMA 和 EMA，但赋予它们不同的功能定位。
## 1. 过滤机制设计

* EMA 定方向（周线过滤层）：在周线定方向（§一）时，使用 EMA34 替代 SMA34。因为周线转空（weekly_bear）需要极高的右侧离场敏感度。用 EMA 可以在周线级别死叉或破位时，比 SMA 提早 1-2 根日 K 线发出强制清仓信号，锁住阶梯止盈（trail_stop）的利润。
* SMA 找买点（日线低吸层）：在日线找买点（§二）时，坚决使用 SMA20/60。因为低吸的核心是寻找“跌不动的强物理支撑”。SMA 在横盘期是一条水平硬支撑，以此作为回踩基准，抓缩量阴跌止跌的准确度显著高于一直在变动斜率的 EMA。

------------------------------
## 🛠️ 针对 v1.44 策略代码架构的微调说明
要在代码层适配 SMA 和 EMA，你需要对 config.py 和指标计算模块做如下微调：

1. 引入 MA_TYPE 参数字典
   在全局 config 或动态预算模块中，不仅要让周期字典化，还要让均线类型字典化。

# 示例内部逻辑表现
STOCK_MA_CONFIG = {
"601398.SH": {"type": "SMA", "fast": 20, "slow": 60, "life": 34}, # 工行偏好传统物理支撑
"513530.SH": {"type": "EMA", "fast": 15, "slow": 45, "life": 21}  # ETF趋势更流畅，用EMA快贴
}

2. 改写 TA-Lib 或 QMT 内置指标的调用入口
   在 14:56 的打卡评估逻辑中，脚本计算主图均线时，不再写死 pyta.MA 或 pyta.EMA，而是做一步简单的条件分支（If-Else判断）：
* 如果当前标的的 type == "EMA"，则调用指数移动平均函数；
    * 如果 type == "SMA"，则调用简单移动平均函数。
3. 注意：移动止盈与时间成本的锚定
   如果某只股票适配了 EMA，它的价格波动会比 SMA 更贴近均线，因此其智能时间强平（time_force 中“破日线 MA60 则强制平仓”的逻辑）会被触发得更频繁。为了防止被 EMA 的高灵敏度误杀，适配 EMA 的标的，其回撤容忍度（TRAIL_TIERS）和硬止损线（STOP_LOSS）可以适当收紧或给予更大的时间豁免宽限（如将 TIME_FORCE_GRACE_BARS 从 5 日放宽至 7 日）。

💡 如何选择推进第一步？
建议先采用方案三（功能分离法）或者方案一（历史回归法）。你可以先在国金 QMT 编辑器中，把单张图的计算公式分别改成 SMA 和 EMA 手动回测对比一下，观察白名单里那几只票（如 601398 银行为代表，513530 跨境ETF为代表）在两种均线下，哪一个能把 diag: ok 的买卖闭合做得最漂亮、无孤儿仓。
