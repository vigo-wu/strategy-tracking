# 沪市可转债上市首日竞价细则

> **依据**：《上海证券交易所可转换公司债券交易实施细则（2025 年 3 月修订）》（上证发〔2025〕42 号）  
> **适用范围**：向不特定对象发行的可转债（代码通常以 **11** 开头），匹配成交  
> **官方入口**：[上交所规则页](https://www.sse.com.cn/lawandrules/sselawsrules2025/bond/convertible/trading/c/c_20250606_10782995.shtml)

以下价格均按面值发行价 **100 元** 换算示例（全价申报；100 元面额 = 1 张；最小变动单位 **0.001 元**）。

---

## 1. 交易时段（匹配成交）

| 时段 | 时间 | 机制 |
| :--- | :--- | :--- |
| 集合匹配 | 09:15 – 09:25 | 集合撮合产生开盘价 |
| 连续匹配 | 09:30 – 11:30、13:00 – **15:00** | 连续撮合至收市 |

与深市的关键差异：

- 沪市 **没有** 14:57–15:00 收盘集合匹配；连续匹配一直到 **15:00**。
- 细则第十二条 **未单独列出**「不可撤单」窗口；集合匹配阶段撤单规则适用《上海证券交易所债券交易规则》一般规定（实务上开盘集合匹配后半段通常不可撤，以主机为准）。
- 14:57 临停复牌后进入的是 **连续匹配**（可挂、可撤、实时撮合），不是收盘集合匹配。

可转债实行 **当日回转（T+0）**。申报数量为 **1000 元面额（10 张）** 或其整数倍；单笔最大不超过 1 亿元面额。

---

## 2. 上市首日涨跌幅与价格边界

| 项目 | 规则 | 发行价=100 示例 |
| :--- | :--- | :--- |
| 首日涨幅限制 | **57.3%** | 上限 **157.30** |
| 首日跌幅限制 | **43.3%** | 下限 **56.70** |
| 首日前收盘价基准 | 以 **发行价格** 作为前收盘价 | 100.00 |
| 开盘集合匹配有效申报 | 发行价上下 **30%** | **70.00 – 130.00** |
| 连续匹配有效申报 | 买卖盘动态笼子（见下节） | 随盘口浮动 |
| 不符合涨跌幅或有效申报范围 | **无效申报** | — |

**非首日**：涨跌幅比例 **20%**；有效申报价格范围与涨跌幅限制范围一致；**无**首日两档临停。

涨跌幅价格公式：`前收盘价 × (1 ± 涨跌幅比例)`，四舍五入至最小变动单位。

---

## 3. 连续匹配有效申报价格范围（首日）

细则第十七条（首日连续匹配）要点：

申报价格须 **同时** 满足：

1. **不高于** 即时揭示最低卖出价格的 **110%**，且 **不低于** 即时揭示最高买入价格的 **90%**；
2. **不高于**「最高申报价与最低申报价平均数」的 **130%**，且 **不低于** 该平均数的 **70%**。

缺档处理：

| 情形 | 处理 |
| :--- | :--- |
| 即时揭示无买入价 | 以「最低卖出价、最新成交价」中的 **较低者** 视为最高买入价 |
| 即时揭示无卖出价 | 以「最高买入价、最新成交价」中的 **较高者** 视为最低卖出价 |
| 当日无成交 | 以前收盘价视为最新成交价 |

策略含义（涨停路径、停在 130 附近复牌时）：

- 笼子锚定的是 **盘口最优买卖价**，不是深市那种单纯「最近成交价 ±10%」。
- 复牌初期若卖一仍在 130 附近，买入有效上限常落在约 **143**（130×1.1）量级，需随成交与盘口上移 **阶梯追单**，才能逐步够到全日上限 **157.30**。
- 任何申报仍不得突破全日涨跌幅 **56.70–157.30**。

---

## 4. 上市首日盘中临时停牌

成交价较 **发行价** 首次触及：

| 档位 | 触发条件 | 停牌时长 | 对应价位（发行价=100） |
| :--- | :--- | :--- | :--- |
| 第一档 | 上涨或下跌 ≥ **20%** | **30 分钟** | 120 / 80 |
| 第二档 | 上涨或下跌 ≥ **30%** | **停至 14:57** | 130 / 70 |

复牌规则（细则第十六条）：

- 临停时间跨越 **14:57** 的，于当日 **14:57** 复牌；
- **未规定**「复牌集合匹配」或「收盘集合匹配」；
- 复牌后直接回到 **连续匹配**，直至 **15:00**。

细则未写明临停期间是否接受匹配成交新增申报；第十七条有效申报条款写的是「连续匹配阶段」。实务上沪市临停期通常 **不接受新增匹配挂单**（与深市临停可挂不同），以交易所/柜台实际受理为准。协商成交在临停或停至收市时本所不接受（第二十七条）。

---

## 5. 首日尾盘路径（沪市核心）

```
… 触及 30% 临停至 14:57 …
        │
14:57:00 ──► 复牌，直接进入连续匹配（无复牌集合、无收盘集合）
        │
14:57–15:00 ──► 连续匹配：可挂可撤，笼子随盘口抬升，阶梯追单
        │
15:00 ──► 收市；收盘价=最后一笔（含）前一分钟成交量加权平均
```

| 阶段 | 机制 | 策略常用挂价（涨停路径） |
| :--- | :--- | :--- |
| 开盘集合匹配 | 发行价 ±30% | 顶格买 **130.00** |
| 临停至 14:57 | 匹配成交新增申报实务上通常不受理 | 不宜依赖临停预挂 |
| 14:57 后连续匹配 | 盘口动态笼子 + 全日涨跌幅 | 从约 **143** 起随最新盘口上移追单，目标不超过 **157.30** |

---

## 6. 开盘价 / 收盘价

- **开盘价**：集合匹配成交价；未能产生的，以连续匹配第一笔成交价为准。
- **收盘价**：匹配成交下，当日最后一笔交易（含）前一分钟所有成交的成交量加权平均价；当日无匹配成交则以前收盘价为收盘价。
- 协商成交等非匹配成交 **不纳入** 开收盘价计算。

## 7. 与策略参数的对应（发行价=100）

| 策略锚点 | 规则出处 | 数值 |
| :--- | :--- | :--- |
| 开盘抢筹限价 | 集合匹配有效申报上限 | **130.00** |
| 14:57 复牌首档追买参考 | 连续匹配笼子（相对盘口约 +10%） | 常约 **143.00** 起 |
| 全日最高限价 | 首日涨幅 57.3% | **157.30** |
| 全日最低限价 | 首日跌幅 43.3% | **56.70** |
| 尾盘机制 | 连续匹配至 15:00 | **可撤、可追单**（非集合竞价） |

## 8. 沪深首日关键差异速查

| 项目 | 沪市（本细则） | 深市 |
| :--- | :--- | :--- |
| 尾盘 14:57–15:00 | **连续匹配** | 复牌集合匹配 → **收盘集合匹配** |
| 收盘集合匹配 | **无** | **有**（不可撤） |
| 连续匹配笼子 | 盘口动态（买一/卖一 ±10% 等） | 最近成交价 **±10%** |
| 临停预挂 | 细则未写接受；实务通常不可新挂 | 细则明确对已接受申报做复牌集合匹配（临停可挂） |
| 首日涨跌幅表述 | 明示涨 57.3% / 跌 43.3% | 以全日有效申报 56.7%–157.3% 等条款约束 |
| 代码 | 11 开头 | 12 / 123 开头 |
