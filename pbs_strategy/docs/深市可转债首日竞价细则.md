# 深市可转债上市首日竞价细则

> **依据**：《深圳证券交易所可转换公司债券交易实施细则（2025 年修订）》（深证上〔2025〕223 号）  
> **适用范围**：向不特定对象发行的可转债（代码通常 12 / 123 开头），匹配成交  
> **说明**：仓库内 `docs/深圳证券交易所交易规则.pdf` 实为《创业板股票上市规则（2026 年修订）》，**不含**下述竞价条文；首日微观结构以本细则为准。

以下价格均按面值发行价 **100 元** 换算示例（全价申报，最小变动单位 **0.001 元**）。

---

## 1. 交易时段（匹配成交）

| 时段 | 时间 | 机制 |
| :--- | :--- | :--- |
| 开盘集合匹配 | 09:15 – 09:25 | 集合撮合产生开盘价 |
| 连续匹配 | 09:30 – 11:30、13:00 – 14:57 | 连续撮合 |
| 收盘集合匹配 | 14:57 – 15:00 | 集合撮合产生收盘价 |

**不可撤单窗口**（交易主机不接受撤销申报）：

- 09:20 – 09:25（开盘集合匹配后半段）
- 14:57 – 15:00（收盘集合匹配）

可转债实行 **当日回转（T+0）**。买入申报数量为 **1000 元面额（10 张）** 或其整数倍。

---

## 2. 上市首日价格边界

| 项目 | 规则 | 发行价=100 示例 |
| :--- | :--- | :--- |
| 全日有效申报上限 | 不得高于发行价 × **157.3%** | **157.30** |
| 全日有效申报下限 | 不得低于发行价 × **56.7%** | **56.70** |
| 开盘集合匹配有效申报 | 发行价上下 **30%** | **70.00 – 130.00** |
| 连续匹配 / 临停期 / 收盘集合匹配有效申报 | 最近成交价上下 **10%** | 随最新价浮动 |
| 超出涨跌幅或有效申报范围的申报 | **无效申报（废单）** | — |

要点：

1. **开盘竞价顶格买价 = 130.00**（发行价 × 1.30）。
2. **全天绝对天花板 = 157.30**；任何时段挂单高于此价均为废单。
3. 连续匹配及之后阶段，笼子是「最近成交价 ±10%」，且不得突破全日 56.70–157.30。
4. 集合匹配无成交时，后续基准价为最近成交价；当日无成交则为前收盘价（首日无前收时按规则以发行价等基准处理）。

**非首日**：涨跌幅限制比例 **20%**；有效申报价格范围与涨跌幅限制范围一致；**无**首日两档临停。

---

## 3. 上市首日盘中临时停牌

成交价较 **发行价** 首次触及：

| 档位 | 触发条件 | 停牌时长 | 对应价位（发行价=100） |
| :--- | :--- | :--- | :--- |
| 第一档 | 上涨或下跌 ≥ **20%** | **30 分钟** | 120 / 80 |
| 第二档 | 上涨或下跌 ≥ **30%** | **停至 14:57** | 130 / 70 |

复牌规则（细则第十六条）：

- 临停时间跨越 **14:57** 的，于当日 **14:57** 复牌；
- 先对 **已接受的申报** 做 **复牌集合匹配**；
- 再进入 **收盘集合匹配**（14:57–15:00）。

实盘含义：早盘常在触及 130 后临停至 14:57；尾盘先撮合一笔复牌价，再进入不可撤单的收盘集合匹配。

---

## 4. 首日尾盘两段撮合（深市核心）

```
… 临停（可接受申报） …
        │
14:57:00 ──► 复牌集合匹配（对已接受申报集中撮合）
        │
14:57–15:00 ──► 收盘集合匹配（不可撤单；±10% 笼子相对最近成交价）
        │
15:00 ──► 收盘价确定
```

| 阶段 | 价格笼子基准 | 策略常用挂价（涨停路径） |
| :--- | :--- | :--- |
| 临停期内提前挂单 | 最近成交价 ±10%，且 ≤157.30 | 停在 130 时上限约 **143.00**（130×1.1）；乱挂 157.30 易废单 |
| 14:57 复牌集合匹配 | 同上（对已接受申报撮合） | 常由高价买单一笔推至顶格附近 |
| 14:57–15:00 收盘集合匹配 | **复牌后最近成交价** ±10%，且 ≤157.30 | 若复牌已至 157.30，则最高只能挂 **157.30** |

收盘集合匹配的成交原则与盘中临时停牌复牌集合匹配相同。

---

## 5. 开盘价 / 收盘价

- **开盘价**：开盘集合匹配产生；不能产生的，以连续匹配第一笔成交价为准。
- **收盘价**：收盘集合匹配产生；不能产生或未进行收盘集合匹配的，取最后一笔匹配成交（含）前一分钟内成交量加权平均价；全日无成交则以前收盘价为收盘价。

## 6. 与策略参数的对应（发行价=100）

| 策略锚点 | 规则出处 | 数值 |
| :--- | :--- | :--- |
| 开盘抢筹限价 | 开盘集合匹配有效申报上限 | **130.00** |
| 临停期预挂上限 | 最近价 130 的 ±10% 上沿 | **143.00** |
| 全日最高限价 / 尾盘锁利卖价 | 全日有效申报上限 | **157.30** |
| 全日最低限价 | 全日有效申报下限 | **56.70** |

## 8. 补充条款

*   **早盘抢筹（买入端）**：深交所遵循严格的“时间优先”原则，排队队列在前一日晚上的“隔夜委托”便已开始。QMT需在前一日交易日晚间（国金证券通常在 **20:30 - 22:30** 之间完成数据清算）开闸的第一毫秒送入前置机。挂单价格精准填报 **130.00元**。
