# 可转债上市首日抢筹策略（PBS / QMT）

依据：`docs/沪市可转债首日竞价细则.md`、`docs/深市可转债首日竞价细则.md`。  
**只做买入抢筹，不含任何卖出逻辑。** 发行价按 **100 元**；申报数量 **10 张** 整数倍。

**核心：14:57 尽快把单挂进柜台；成交可遇不可求。**  
开盘/隔夜 130 由人工委托。若人工已成交，init 对账后见仓即停。

---

## 1. 目标

| 模式 | 路径 |
| :--- | :--- |
| **开盘（人工）** | 隔夜/开盘集合顶格 **130.00**；策略不参与 |
| **B 尾盘（策略）** | **14:56** 预热手数 → **14:57** 准点+50ms 轮询挂 **157.30**；柜台见单 = 成功 |

---

## 2. 执行节奏

1. `14:56`：`CLOSE_PREWARM` 算好价/量（`close_prewarm`）  
2. `14:57:00`：`run_time` 准点开火 + 50ms 定时器重试；**先挂单**再拉行情/状态  
3. `passorder` 成功 → pending；见单前**只查委托**不查成交  
4. 柜台见单 → `order_acked`（目标达成）；之后 pending 降频（`PENDING_AFTER_ACK_POLL_SEC`）  
5. 长期未见单（默认 5s）→ 委托查询确认仍无 → 影子强清 → 冷却 2s 后重挂  

---

## 3. 风控

1. 申报价默认 `LIMIT_UP_PRICE`；可用 `CLOSE_BUY_PRICE` 覆盖  
2. 必须配置 `LISTING_DATE_MAP`（快路径靠 map，无行情往返）  
3. 人工隔夜未成单须自行处理，否则可能双挂  
4. 主图分笔；实盘定时器 50ms + 14:56/14:57 准点槽
