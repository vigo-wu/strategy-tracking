# 可转债上市首日抢筹策略（PBS / QMT）

依据：`docs/沪市可转债首日竞价细则.md`、`docs/深市可转债首日竞价细则.md`。  
**只做买入抢筹，不含任何卖出逻辑。** 发行价按 **100 元**；申报数量 **10 张** 整数倍。

**开盘/隔夜 130 由人工委托**；本策略**只跑尾盘**：14:57 起直接以 **157.30** 申报，失败则持续重试直至申报成功。若人工已成交，init 对账后见仓即停。

---

## 1. 目标

| 模式 | 路径 |
| :--- | :--- |
| **开盘（人工）** | 隔夜/开盘集合顶格 **130.00**；策略不参与 |
| **B 尾盘（策略）** | **14:57** 起挂 **157.30**（`LIMIT_UP_PRICE`）；申报失败则重试直至成功 |

价格锚点：

| 锚点 | 数值 |
| :--- | :--- |
| 开盘抢筹（人工） | **130.00** |
| 收盘申报（策略） | **157.30** |

---

## 2. 深市 / 沪市（统一）

| 阶段 | 买入动作 |
| :--- | :--- |
| 隔夜 / 开盘集合 | **人工**挂 **130.00** |
| **14:57:00–14:59:55** | 策略以 **157.30** 限价买；`passorder` 失败或废单清 pending 后继续重试，直至申报进场（有 pending）或已成交 |

深市收盘集合 **不可撤**；成功申报后策略不再撤补。沪市连续匹配同样顶格挂出，不追笼子阶梯。

若 `passorder` 本地成功：以柜台查到委托（`order_acked`）为委托成功。长期未见单：`age≥3s`、成交查询**成功且量为 0**、命中间隔累计后二次确认，才清影子；随后 `PENDING_SHADOW_REORDER_COOLDOWN_MS`（默认 2s）内禁止重挂。若委托已无但成交有量 → 先记账，不重挂。

---

## 3. 风控

1. 申报价默认 = `LIMIT_UP_PRICE`（157.30）；可用 `CLOSE_BUY_PRICE` 覆盖  
2. 已持仓 / 已成交即停；人工成交靠 init 对账  
3. 人工隔夜未成单须自行在尾盘前处理，否则可能双挂  
4. 实盘务必配置 `LISTING_DATE_MAP`  
5. 主图 **分笔**；实盘 **`run_time` 定时器**（默认 50ms）+ 分笔双驱动  
6. 模型宜在 **14:57 前** 已加载运行  

---

## 4. QMT 部署

```text
python pbs_strategy/scripts/qmt/_deploy_qmt_gbk.py
```

| 项 | 值 |
| :--- | :--- |
| 入口 | `PbsRush.py` / `转债首日抢筹.py` |
| 主图 | **分笔（tick）** |
| 实盘驱动 | 定时器 50ms + 分笔 |
| 时窗 | `CLOSE_BUY_START`–`CLOSE_BUY_END`（默认 145700–145955） |
| 申报价 | `CLOSE_BUY_PRICE` 或 `LIMIT_UP_PRICE` |
