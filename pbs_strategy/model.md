# 可转债上市首日抢筹策略（PBS / QMT）

依据：`docs/沪市可转债首日竞价细则.md`、`docs/深市可转债首日竞价细则.md`。  
**只做买入抢筹，不含任何卖出逻辑。** 发行价按 **100 元**；申报数量 **10 张** 整数倍。

---

## 1. 目标

在上市首日尽快买到筹码。早盘顶格优先；未成则尾盘按沪/深微观结构继续抢。

| 模式 | 路径 |
| :--- | :--- |
| **A 早盘** | 顶格挂 **130.00**（开盘集合有效上限） |
| **B 尾盘** | 早盘未成 → 深市临停预挂 / 沪市复牌阶梯追，目标买到 |

价格锚点：

| 锚点 | 数值 |
| :--- | :--- |
| 开盘抢筹 | **130.00** |
| 复牌首档笼子上沿 | **143.00**（130 × 1.1） |
| 全日最高可挂 | **157.30**（超限=废单） |

---

## 2. 深市（`.SZ` / 12x）

临停期可挂；尾盘 = 复牌集合 → 收盘集合（14:57–15:00 **不可撤**）。笼子 = 最近成交价 ±10%。

| 阶段 | 买入动作 |
| :--- | :--- |
| 前夜清算后 / 首日 09:25 前 | Mode A：挂 **130.00** |
| 临停期内（≥09:30，≤14:54:59） | Mode B：预挂 **143.00**（禁挂 157.30；尽早挂以吃时间优先） |
| **14:55:00–14:56:59** | **必须撤掉未成 143**（赶在不可撤窗口前） |
| 14:57:01 后 | **等复牌 last≥143（笼子已能到 157.30）** 再按笼子顶挂一次；默认 **14:57:45** 仍未就绪则强制按当前笼子挂（可能仍是 143）；收盘集合内不再撤补 |

若 14:57 后 143 仍未撤掉 → 策略告警并放弃升级（不可撤）。

---

## 3. 沪市（`.SH` / 11x）

临停实务通常不接受新挂；14:57 起 **连续匹配**至 15:00（可挂可撤）。笼子锚定盘口（卖一 ×1.1 等）。

| 阶段 | 买入动作 |
| :--- | :--- |
| 09:24:59.850–09:24:59.950 | Mode A：卡点挂 **130.00** |
| 临停期 | 不预挂 |
| 14:57–15:00 | Mode B：按笼子上限阶梯撤补，目标 **157.30**；节流 ≥50ms |

---

## 4. 风控

1. 任意挂单 > **157.30** = 废单  
2. 深市收盘集合不可撤；**撤 143 必须在 14:57 前完成**  
3. 早盘未成单撤单若超过 `AM_CANCEL_STUCK_SEC` 仍不清 → **强清影子 pending**，放行 Mode B（柜台残留单需人工确认）  
4. 沪市复牌不得早于 14:57:00；追单注意券商 TPS  
5. 买到即止；本策略**不会**下卖单  
6. 实盘务必配置 `LISTING_DATE_MAP`，否则隔夜单/首日门闩可能 fail-closed  
7. 卡点与追单：主图 **分笔**；实盘另开 **`run_time` 定时器**（默认 100ms）双驱动——定时器管准点，分笔/全推管取价  
8. 定时器内 `quickTrade=2`；分笔路径 `quickTrade=1`；`A.busy` 防重入  

---

## 5. QMT 部署

```text
python pbs_strategy/scripts/qmt/_deploy_qmt_gbk.py
```

| 项 | 值 |
| :--- | :--- |
| 入口 | `PbsRush.py` / `转债首日抢筹.py` |
| 主图 / 回测周期 | 上市首日可转债，**分笔（tick）** |
| 实盘驱动 | **定时器 `run_time`（默认 100ms）+ 分笔 handlebar**；回测仅分笔 |
| 默认 | `DRY_RUN=True`；`ENABLE_LIVE_TIMER=True`；`LIVE_TIMER_MS=100` |
| 上市日 | **必须**填 `LISTING_DATE_MAP` |

实盘前：NTP、可转债+QMT 权限、足额现金；主图确认为分笔；确认 `DRY_RUN=False`。

**调度说明**：实盘 = 定时器墙钟驱动（竞价/临停准点）+ 分笔 handlebar（有行情补跑）+ `get_full_tick` 取价。回测无 `run_time`，靠分笔回放。`LIVE_TIMER_MS` 建议 50–100，注意券商 TPS。
