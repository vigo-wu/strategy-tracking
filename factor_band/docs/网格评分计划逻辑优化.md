# 网格评分曲线优化

针对「资金防御」非线性惩罚、「时空复原」阶梯平滑、「空间泛化」防刷分：只改曲线形状，各维与总分仍落在 0–100；不改权重、侧栏旋钮、不重跑 walk。

公式唯一可信数据源：[`网格评分设计.md`](网格评分设计.md)。实现：`.cursor/skills/qmt-local-bt-grid/scripts/grid_score.py`（`_s_dd` / `_s_decay` / `s_gen` / `score_cell`）。

写死常量（不上侧栏）：`DD_BREACH_MULT=0.2`、`GEN_LUCK_CAP=80`。

---

## 1. 资金防御：回撤平方惩罚 + 触顶软乘

**痛点。** 线性 `100×(1 − DD/dd_cap)` 在低回撤区过严、高回撤区过松；触顶后仅回撤分归零，总分仍可能靠结构/复原撑高。

**公式（`_s_dd`）。**

$$
S_{\text{回撤}} =
\begin{cases}
100 \times \left(1 - \left(\frac{DD_{\max}}{\texttt{dd\_cap}}\right)^2\right)
& \text{if } DD_{\max} < \texttt{dd\_cap} \\
0 & \text{if } DD_{\max} \ge \texttt{dd\_cap}
\end{cases}
$$

**触顶软惩罚（`score_cell`）。** 同账户 `all` / `tune` / `check` 最坏 `|max_dd| ≥ dd_cap` 时，加权总分再乘 `DD_BREACH_MULT=0.2`（取消硬门否决，软压到几乎不可推荐）。盲测篮回撤不参与触顶判定。

**示例（`dd_cap=0.35`）。** 回撤 5% → ≈97.96；30% → ≈26.53；≥35% → 回撤分 0 且总分 ×0.2。

---

## 2. 时空复原：年化衰减 Hermite 平滑

**痛点。** 旧分段在 `r=0.5` 两侧一阶导数不连续，挤在 0.48–0.52 时排序抖动。

**公式（`_s_decay`）。** `r =` 验收几何年化 / 调参几何年化。任一窗年化为负、缺值、或调参年化 ≤0 → 0。

$$
S_{\text{年化衰减}} =
\begin{cases}
50 & \text{if } r \ge 1 \\
50 \times (3r^2 - 2r^3) & \text{if } 0 \le r < 1 \\
0 & \text{if } r < 0 \text{ 或缺值}
\end{cases}
$$

`r=0.5` 仍得 25，与旧分段锚点对齐；灵敏度集中在约 0.3–0.7。

---

## 3. 空间泛化：取消「调参≤0 → 满分」

**痛点。** 调参全区间夏普 ≤0 且盲测 >0 直接给 100，易把「撞大运」格刷上推荐。

**逻辑（`s_gen`，需 `sharpe_target`）。** 无空间隔离 → `null`（摊权）。缺盲测窗 → 0。用 `sharpe_target` **锚定盲测绝对强度**（连续打分，**不是** `s_h < target → 0` 硬门否决）。

| 情况 | 条件 | 得分 |
| :--- | :--- | :--- |
| A 双正 | 调参 >0 且 盲测 >0 | `100 × min(1, 盲测/调参)` |
| B 过拟合 | 调参 >0 且 盲测 ≤0 | `0` |
| C 撞大运 | 调参 ≤0 且 盲测 >0 | `min(GEN_LUCK_CAP, 50 × 盲测/sharpe_target)`，封顶 **80** |
| D 双负 | 调参 ≤0 且 盲测 ≤0 | `0` |

情况 C 在 `盲测 = sharpe_target` 时得 50（及格锚），再好也拿不满分。

---

## 落地

改旋钮或曲线后对已有 sweep 做「只汇总」/ `--summarize-only` 即可重排推荐，不必重跑 walk。不改 `config.py`、不 deploy。
