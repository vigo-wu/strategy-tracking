# 任务目标
请帮我实现一个量化交易的自定义技术指标。该指标的核心逻辑是计算移动平均线（SMA/EMA）的“线性回归斜率”，并通过“斜率归一化”消除股票/品种之间绝对价格差异的影响。

# 输入参数
- 基础价格数据 (Price): 默认使用收盘价 (Close)。
- 均线周期 (N): 默认值为 20，用于计算基础移动平均线。
- 斜率窗口 (M): 默认值为 5，用于计算最近 M 根 K 线内均线的线性回归斜率。

# 核心计算逻辑与数学公式
1. 基础均线计算 (MA):
   计算 N 周期的移动平均线。
   公式: MA_N = Average(Close, N)

2. 线性回归斜率计算 (Slope):
   以时间序列 [1, 2, ..., M] 作为自变量 X，以最近 M 天的 MA_N 数值作为因变量 Y。
   使用最小二乘法 (OLS) 拟合一条直线，求出该直线的斜率 (Slope)。
   公式: Slope = (M * Σ(X*Y) - ΣX * ΣY) / (M * Σ(X^2) - (ΣX)^2)

3. 斜率归一化 (Norm_Slope) - 核心步骤:
   为了消除高价股和低价股的量纲差异，将绝对斜率 (Slope) 除以当前的均线价格，并乘以 100，将其转化为“每日均线变动的相对百分比”。
   公式: Norm_Slope = (Slope / MA_N) * 100

# 输出要求
1. 请输出一个相对数值序列 (Norm_Slope)，其值代表均线每天涨跌的百分比。
2. 基础逻辑对应：
    - Norm_Slope > 0 轴，代表均线上升。
    - Norm_Slope < 0 轴，代表均线下降。
    - Norm_Slope 接近 0，代表均线走平。
