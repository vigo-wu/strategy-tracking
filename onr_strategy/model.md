## 结论（先看）

策略形态合法（T 日买、T+1 卖，与 A 股 T+1 对齐），但原文把 Alpha 说成「捕捉隔夜跳涨溢价」。公开研究里 A 股全市场平均隔夜收益（昨收到今开，C2O）长期显著为负、日内为正；样本又落在 30–150 亿自由流通市值的中小盘，隔夜折价通常更重。过滤后能否把隔夜符号翻正，**目前没有真实行情回测**（§9 脚手架可接 CSV）。

另外：原文在 14:45 决策，却用 14:55 / 15:00 数据；推荐 14:56:30 追价，落在连续竞价而不是收盘集合竞价。这两处不修，回测和实盘都会系统性偏乐观。

建议顺序：**冻结无前视规格 → 成本后回测（相对同池随机隔夜）→ 再谈 QMT**。脚手架已按 §2 可交易列冻结 P1–P12 提案（大单默认关）。未过回测闸门前不要写交易脚本。

## 核心逻辑

在尾盘多空相对明朗后，从全 A 中筛「趋势完好 + 当日已有涨幅但未透支 + 尾盘仍有买盘」的少量标的，争取收盘集合竞价成交，次日早盘按开盘强弱了结。持股约一个隔夜，不做波段股东。

意图上的收益来源有两段，不要混成一句「隔夜溢价」：

| 段 | 定义 | 原文期望 | 需要先验证的事 |
| :--- | :--- | :--- | :--- |
| 隔夜 | 买入价 → T+1 开盘价 | 跳涨 | 过滤后 C2O 是否显著为正（全市场均值一般为负） |
| 早盘 | T+1 开盘 → 5～15 分钟内卖出 | 冲高多吃一段 | 高开后是否经常冲高回落；低开止损是否卖在最差价 |

行情与均线一律按**前复权**理解（落地时与仓库其他策略一致：`dividend_type=front_ratio`）。决策用的「今日价格」是当时最新价，不是未走完的日线收盘价。

```mermaid
flowchart LR
  U[全 A] --> P[基础池]
  P --> F[14:45 因子]
  F --> L[1 至 5 只名单]
  L --> R[14:50 风控剔除]
  R --> A[14:57 收盘集合竞价买入]
  A --> X[T+1 早盘按开盘分档卖出]
```

## 一、基础池

进入因子计算前必须先过硬门槛。池子每日重算。

| 门槛 | 规则 | 目的 |
| :--- | :--- | :--- |
| 合规 | 剔除 ST、\*ST、退市整理 | 交易与流动性风险 |
| 次新 | 上市未满 **60 个交易日** 剔除 | 筹码不稳定 |
| 流动性 | 过去 **20** 个交易日日均成交额 **> 1.5 亿元** | 拒绝僵尸股 |
| 市值 | 自由流通市值 **30 亿～150 亿元** | 弹性与控盘之间的折中 |

未写明、落地时默认：

- 不含北交所（流动性与竞价细节不同）。
- 不含停牌、当日临时停牌未在 14:45 前复牌、涨跌停无法买入的标的。
- 科创板 / 创业板 20% 涨跌停仍适用同一涨幅窗 3%～6%（见 §2）。

## 二、选股因子

**触发**：每个交易日 **14:45** 对基础池打一遍。  
**通过标准**：下表「可交易截断」列全部满足（AND）。原文若干公式用到 14:55 / 15:00，那是前视，只保留在「原文」列对照。

均线：用 14:45 最新价当作「今日未完成 K」的价格，再与前 4 / 9 / 19 个已收盘日计算 MA5 / MA10 / MA20。斜率用当日该均线减昨收对应均线，要求 `> 0`。

### 1. 技术形态

| 因子 | 可交易截断（14:45） | 原文 | 说明 |
| :--- | :--- | :--- | :--- |
| 均线多头 | 价 ≥ MA5 > MA10 > MA20，且 MA5、MA10 斜率 > 0 | 同左 | 排除下跌趋势里的反弹 |
| 当日涨幅 | 相对昨收 **3%～6%**（含边界） | 同左；文案另写「高于 7% 易炸板」，与硬阈值 6% 不一致，以 **6%** 为上限 | 低于 3% 当动能不足；接近涨停当透支隔夜 |
| 上影控制 | `(当日最高 − 现价) / 现价 < 1.5%` | 同左 | 要求价格仍在当日高位附近 |

### 2. 尾盘动量与盘口

| 因子 | 可交易截断（无前视） | 原文（含前视，禁止直接回测） |
| :--- | :--- | :--- |
| 尾盘动量 | `(P_14:45 − P_14:30) / P_14:30 > 0.8%`，且 14:30–14:45 分钟线无大幅回撤 | 用 **P_14:55**；14:30–14:55 分时稳定向上 |
| 分时回撤 | **待量化**。建议：14:30 后任意分钟收盘相对区间峰值回撤 `< 0.5%` | 「无大幅回撤」，无数字 |
| 大单贡献 | 14:30–**14:45** 分时成交中，单笔金额 ≥ **100 万元** 且主买，占该时段成交额 **> 40%** | 统计到收盘；依赖 Level-2 / 逐笔 |
| 尾盘量比 | `(14:30–14:45 每分钟均量) / (09:30–14:30 每分钟均量) ≥ 1.5` | 分子用到 **14:30–15:00** |

「主买」落地时必须写死口径（逐笔主动买入 / 成交价 ≥ 当时卖一 等），否则无法复现。无 Level-2 时该因子标为不可用，不得用日线「资金流」近似后仍声称同一策略。

### 3. 市场与行业

| 因子 | 可交易截断 | 原文 | 缺口 |
| :--- | :--- | :--- | :--- |
| 行业 | 标的所属**申万二级**行业指数当日涨幅（用 14:45 行业指数点位 vs 昨收）排全市场 **前 15%** | 同左；文案偏好「龙二 / 龙三」 | 「龙二 / 龙三」未定义，落地只保留分位门槛 |
| 大盘 | 14:30–14:45 上证指数与创业板指均未满足「放量下跌」 | 统计到更晚 | 「放量下跌」待量化，见 §7 |

14:45 之后到下单前，价格跌破涨幅下限 3%、或上影条件失效，应从名单剔除（原文 14:50 人工检查的可自动化部分）。

## 三、执行

为避开 14:30–14:45 的假拉升，买入集中在**收盘集合竞价**，不要在 14:57 前用可立即成交的超价限价单去「抢收盘」。

| 时刻 | 动作 |
| :--- | :--- |
| 14:45 | 跑 §2，输出通常 1～5 只 |
| 14:50 | 剔除突发利空、明显对倒砸盘、条件已失效的标的 |
| **14:57:00 起** | 提交**限价**买单，进入 14:57–15:00 收盘集合竞价（该时段**不可撤单、不接受市价**） |
| 15:00 | 按集合竞价唯一价成交；限价 ≥ 成交价且有对手量则成交 |

**不要**在 14:56:30 用「高 2～3 个买档」或「现价 +0.5%～1%」下单：14:57 前仍是连续竞价，超价限价会按当时卖盘立刻成交，买到的不是 15:00 收盘价，滑点往往达到几十到上百 bp，隔夜薄 Alpha 会被一次吃掉。

集合竞价限价建议（待回测校准，不是已验证最优）：

- 限价 = `min(涨停价, max(虚拟匹配价, 14:57 前最新价) × (1 + 缓冲))`
- 缓冲初值 **0.3%～0.5%**，只为提高成交概率；成交价仍是集合价
- 未成交则当日空仓，不转日连续竞价追买

连续竞价阶段未成交、且限价仍挂着的单，会进入收盘集合竞价且 14:57 后不能撤。若 14:57 前误挂超价单，可能已经成交，风控上应避免提前挂单。

### 资金

| 项 | 规则 |
| :--- | :--- |
| 当日买入只数 | 最多 **3** 只（因子通过超过 3 只时的排序键 **待定**，见 §7） |
| 单只仓位 | 总资产的 **10%～15%** |
| 当日总仓 | 约 30%～45%，禁止单只尾盘满仓 |

## 四、次日出局

T+1 无论盈亏都要有动作；**禁止**把隔夜做成中线。下表三档是原文已写明的；两档之间的开盘涨跌幅原文没有规则。

相对昨收（即买入日收盘，若集合竞价成交则买入价 ≈ 昨收）计算开盘涨跌幅 `g = 开盘 / 昨收 − 1`。

| 开盘 | 动作 | 细节 | 规格状态 |
| :--- | :--- | :--- | :--- |
| `g > 1.5%` | 分批/择时止盈 | 开盘后若脉冲，跌破 **5 分钟均线**或分时均线则全额卖出；若 **一字涨停**则继续持有 | 已写；一字板后续卖点未定义 |
| `−0.5% ≤ g ≤ 0.5%` | 限时平仓 | 开盘后 **15 分钟**内无「主力拉升冲高」则平仓 | 「拉升冲高」待量化 |
| `g < −1%` | 止损 | 跌破成本 **−2%**，或开盘 **5 分钟**内不能收复平盘，无条件卖 | 两条件优先级未定义 |

**原文未覆盖，必须先拍板再回测：**

| 缺口 | 建议（仅提案，未写入生效规则） |
| :--- | :--- |
| `0.5% < g ≤ 1.5%` | 按高开档处理（盯 5 分钟线） |
| `−1% ≤ g < −0.5%` | 按低开档处理（更快止损） |
| 一字涨停未开板 | 持有至开板当日，开板后改走高开/平开规则；连续一字的持有上限（如 3 日）待定 |
| 开盘涨停买不进卖不出 | 能卖则按高开；封死则持有 |
| 买入日收盘涨停导致未买到 | 当日无仓，不补买 |

卖出在连续竞价。T+1 可卖数量以券商持仓「可卖」为准（回测须模拟 T+1 锁仓）。

## 五、可行性

### 1. 制度：可做

买在 T 日收盘、卖在 T+1，正好落在 T+1 约束内。这是原文里最干净的一部分。不能做成「当天买当天卖」。

### 2. 收益假设：与市场平均结构相反，过滤效果未知

| 来源 | 与原文的关系 |
| :--- | :--- |
| 中信建投（2025）隔夜–日内专题：A 股平均 C2O 显著为负、日内为正 | 原文「隔夜跳涨溢价」更像美股叙事，不是 A 股全市场事实 |
| 隔夜折价在小盘、高波动期更明显 | 本策略市值窗正在中小盘 |
| 零售统计里「尾盘拉升、次日低开」出现频率不低（口径杂、不可当论文） | 尾盘放量本身也可能是做收盘/诱多，和大单因子同向或反向都说得通 |

因此：全市场无过滤的「收盘买、开盘卖」期望为负；本策略是**条件选股 + 早盘择时卖**，有可能翻正，也有可能把诱多样本买得更准。没有扣除成本、无前视的分层回测之前，不能当 Alpha 已存在。

### 3. 规格：当前不能无偏回测

- 决策时点与因子时点错位（14:45 vs 14:55/15:00）。
- 涨幅上限 6% 与文案 7% 冲突。
- 出局表覆盖不全；「放量下跌」「分时无回撤」「拉升冲高」未量化。
- 问财语句（附录）只覆盖基础池 + 部分形态 + 行业，**不是**完整策略。

### 4. 成交：原文下单时点会毁掉薄边

收盘集合竞价是 14:57–15:00，限价、不可撤。按原文 14:56:30 超价，会在连续竞价成交。正确集合成交时，往返摩擦大约是佣金双边 + 卖出印花税约 5 bp + 集合冲击；错误时点追价则可能先亏 50～100 bp，再去赌隔夜。

### 5. 容量与拥挤

零售资金、3 只 × 10%～15%、标的日均成交 > 1.5 亿，容量一般够。拥挤点在 14:57 同一批「尾盘强势股」上的集合买盘，可能把收盘价买贵、把次日开盘卖压加大。回测要用集合竞价或至少「收盘价 + 冲击」而不能用 14:45 价当买入价。

### 6. 工程：不像现有单仓主图模型

本仓库终端策略（如 `hongli_band`）是**主图单标的** + `qmt_common` 拼接。ONR 是**全市场扫描 + 收盘集合竞价 + 次日分钟级出场**，更接近选股引擎，而不是挂在一只股票上的 `handlebar`。

| 能力 | 难度 | 说明 |
| :--- | :--- | :--- |
| 日线基础池、均线、涨幅、上影 | 低 | 日线 + 14:45 快照即可 |
| 分钟动量、量比 | 中 | 全市场分钟线，14:45 定时任务 |
| 100 万主买占比 | 高 | Level-2 / 逐笔；QMT 终端模型不合适 |
| 申万二级分位 | 中 | 要行业成分与行业指数 |
| 收盘集合竞价报单 | 中 | 限价、不可撤、虚拟匹配价 |
| 次日 5 分钟线止盈 | 中 | 持仓标的分钟行情，不是全市场 |

结论：**逻辑上可交易，规格上未完成，假设上未验证。** 可行性 = 先证伪隔夜段，再谈自动化。

## 六、回测闸门（通过前不写实盘脚本）

基线：同日基础池内随机 3 只、收盘买次日开盘卖（扣成本）。策略必须在扣成本后稳定高于这条基线，才说明因子有用，而不是在吃「随机隔夜」。

必做：

1. 全部因子只用决策时点可得数据（§2 可交易列）。
2. 买入价用收盘集合价或「收盘 + 冲击」；禁止用 14:45 价。
3. 卖出价用开盘 / 5 分钟规则的可成交价，涨跌停无法成交要记未成交。
4. 样本至少覆盖 2019 至今，分开牛、熊、震荡；单独看周一（周末信息）。
5. 因子逐项剔除（ablation）：尤其大单、行业、涨幅窗。
6. 对比三种卖法：开盘全出、按 §4、持有到 T+1 收盘。
7. 成交笔数、空仓日、单日最多 3 只、T+1 锁仓要在日志里对得上。

未过闸门的接受标准：隔夜段扣成本后相对基线无显著正期望，或主要来自某一年/某一板块。

## 九、回测脚手架

路径：`onr_strategy/backtest/`。这是**离线 Python**，不是国金终端模型，不要当 `qmt_terminal_*.py` 导入。

冻结口径：

- 因子只用 `<= 14:45` 的分钟线（P1/P2）；14:50 只复查涨幅/上影。
- 买入价 = 当日 `close × (1 + buy_impact)`，默认冲击 0，**不用 14:45 价**。
- 大单因子默认关（P12）；打开且无 `large_buy.csv` 则剔除，不会用日线资金流代替。
- 行业因子默认关；缺 14:45 行业收益则失败，不会用行业日收盘代替。
- 出局 `--exit open|rules|next_close`。`rules` 使用 §7 提案 P7–P10，高开/低开未在 10:00 前触发则强制出（隔夜策略不做股东）。
- 每次运行同时打一条同日基础池随机 3 只、次日开盘卖的基线。

```bash
python -m unittest discover -s onr_strategy/tests -t .
```

落盘会先下日线，再只对「日涨幅落在约 1.5%–9% 或冲高≥3%」的股票日下 1 分钟线，压成 `intraday.csv`（14:45 因子）+ 稀疏 `minute.csv`（09:30–10:00 与 14:30–14:50）。指数保留足够分钟线做 P5。流通市值用**当前**流通股本 × 当日收盘，有股本变动偏差。行业/Level-2 仍默认不落。

`--demo` 是合成样本，只用来验管道（无前视、T+1、基础池剔除），**不是**市场结论。

CSV 长表（目录内）：

| 文件 | 用途 |
| :--- | :--- |
| `meta.csv` | `symbol,name,list_date,is_st,sw2,exchange` |
| `daily.csv` | `date,symbol,open,high,low,close,volume,amount,pre_close,float_mkt_cap,suspended` |
| `intraday.csv` | 可选，14:45 压缩因子（`dump_xtdata` 写出；有则优先于全日分钟线） |
| `minute.csv` | `datetime,symbol,open,high,low,close,volume,amount`（可只含早盘/尾盘窗） |
| `index_minute.csv` | 可选，上证/创业板分钟线，列同 minute |
| `industry_1445.csv` | 可选，`date,sw2,ret`（14:45 行业涨幅） |
| `large_buy.csv` | 可选，`date,symbol,ratio`（14:30–14:45 主买大单占比） |

分钟线必须含 09:30–14:45；T+1 出场还需要次日开盘后分钟线。`float_mkt_cap` 与 `amount` 单位为元。上市日早于样本首日的标的视为已过 60 日次新。前复权由数据源保证。

`--out` 写 `strategy_trades.csv` / `strategy_days.csv` 以及基线对照。成交行含 `overnight_ret`、`morning_ret`、`net_ret`、`t1_weekday`，对应 §6 拆段与周一。
