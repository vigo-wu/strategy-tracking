## 核心逻辑

在 **15 分钟** 上做多头趋势里的缩量回踩 MA20。1 小时趋势 + 15m 多头排列定方向，时段 / 大盘 / 量能过滤假摔，锤子或放量反包确认后次根开盘买。T+0 下止损、衰竭、止盈在次根开盘即可卖。行情一律 **前复权**。

一票最多 `SCALE_MAX` 笔独立仓。涨停买不进、跌停卖不出按经纪层拒单，状态保留 pending。卖出成交后允许当日再开（T+0 回合）。

## 一、周期与均线

| 角色 | 周期 | 算法 | 参数 |
| :--- | :--- | :--- | :--- |
| 操盘线 | 15m | SMA | `MA_FAST=20` |
| 趋势线 | 15m | SMA | `MA_SLOW=60` |
| 小时趋势 | 1h | SMA | `H_MA_FAST=20`、`H_MA_SLOW=60` |

**15m 多头排列**（`trend_ok`）：`MA20 > MA60`；`MA60` 不下行；`close > MA60`。回踩当根不要求 MA20 上行（快线走平是回踩常态）。

**1h 趋势向上**（`h1_ok`）：截到当前信号 15m 结束时刻；`hMA20 > hMA60` 且 `hMA20[t] >= hMA20[t-1]`（允许走平）。

暖机：15m 至少 80 根、1h 至少 80 根有效 K，否则 `diag: short`。

---

## 二、过滤（任一不满足则该 bar 不开）

### 1. 时段（`time_skip`）

15m 按 **结束时刻**（QMT `timetag` 为区间右端：09:30–09:45 记为 09:45）。

| 窗口 | 结束时刻 | 动作 |
| :--- | :--- | :--- |
| 早盘噪音 | `09:45` | 禁开 |
| 上午 | `10:00`–`11:30` | 允许（`10:00` 次根 `10:15` 成交） |
| 下午 | `13:15`–`13:45` | 允许（最晚次根 `14:00` 成交） |
| 午后偏晚 | `14:00`、`14:15` | 禁开（次根 `14:15`/`14:30` 成交，隔夜缺口） |
| 尾盘 | `14:15` 及之后成交 | 已挂买入 pending 作废（`entry_late_skip`；含 `14:30`/`14:45`/`15:00`） |

### 2. 大盘（`index_dump_skip` / `index_na_skip`）

上证 `000001.SH` 同一根 15m：`(close-open)/open <= INDEX_DUMP_RET`（`-0.004`）且 `vol >= MAVOL20 × INDEX_DUMP_VOL`（`1.5`）→ 禁开。指数取数失败 → `index_na_skip` 禁开。

### 3. 缩量（`vol_skip`）

- `vol < MAVOL20 × VOL_PULLBACK_RATIO`（`0.85`）
- 锤子 / 反包 / 回踩阳一律要过缩量（v0.8 曾对锤子免缩量，10-31/3-6/7-30 大亏）

## 三、买入（`pullback_ma20`）

前提：`h1_ok` 且 `trend_ok`，且 §二通过。同一根 **已收盘** 15m 上：

1. **靠拢**：`low <= MA20 × (1 + MA_TOUCH_TOL)`（`0.004`）
2. **未有效跌破**：`close >= MA20 × (1 - MA_BREAK_TOL)`（`0.002`）
3. **形态**（其一）
   - `hammer`：下影 `>= 1.5 × body`；`body/range <= 0.50`；收盘在区间上半且 close >= open
   - `bounce`：收阳、下影不少于实体（或振幅 20%）、收盘上半；弱于锤子
   - `engulf`：上一根阴线；本根阳线实体完全包住上一根实体；`vol > vol[t-1]`
4. 挂 `pending_entry`，**下一根 15m 开盘**买入

不成交：当日后续 15m 开盘仍可执行；**隔日作废**。废单后若仍在当日允许窗可重试。

仓位：每笔 `TRADE_BUDGET=50000`，整百股；实盘再乘 `CASH_RATIO=0.8`。  
**加仓**（`SCALE_ENABLE`）：已有仓且任一笔持仓期最大浮盈 `>= SCALE_ARM`（`0.015`）时，下一笔合格回踩再买一笔预算，最多同时 `SCALE_MAX=2` 笔。等加仓时硬止盈让路（15m 趋势仍在，且该笔持仓根数 `< SCALE_GIVEUP_BARS=80`）。账户要能再拿出一笔预算。  
**多仓**（`SCALE_LOTS`，默认开）：记账在共用模块 `scripts/qmt_common/single/lots.py`。每笔自己的成本、收盘最高、持仓根数；止盈 / 回吐 / 成本止损 / stall / trend_break **按笔**出。`stop_ma`（跌破 MA20）仍一次出清剩余各笔。第一笔可以先止盈，第二笔继续拿。  
关 `SCALE_LOTS` 则退回 v1.2：均价合并、整仓出；此时 `SCALE_RESET_PEAK` 才会在加仓后重置峰值。

## 四、卖出（T+0，次根开盘）

信号收盘确认 → 下一根 15m 开盘卖。券商可卖为 0 时 skip，**不清仓状态**。

| 优先级 | 卖点 | 条件 | 日志码 |
| :--- | :--- | :--- | :--- |
| 1 | MA 止损 | 收盘时刻 `>= 10:15` 且 `< MA20 × (1 - STOP_MA_PCT)`，`0.008` | `stop_ma` |
| 2 | 成本止损 | **该笔** `close <= cost × (1 - STOP_LOSS)`，`0.02` | `stop_loss` |
| 3 | 趋势破坏 | 15m `trend_ok` 已假，**该笔**当前浮亏 `<= TREND_BREAK_MIN_RET`（-0.4%），**且该笔最大浮盈 `< 0.1%`**，时刻 `>= 10:15` | `trend_break` |
| 4 | 离开均线硬止盈 | 默认开。**该笔**浮盈 `>= TAKE_PROFIT` 且离开 MA20；**若未加满且趋势仍在则让路等加仓** | `take_profit` |
| 5 | 回吐跟踪 | **该笔**收盘最高浮盈 `>= TAKE_PROFIT`（`0.015`）后，相对该笔收盘最高回吐 `GIVEBACK`（`0.008`）；最高浮盈 `>= 4%` 后改为 `GIVEBACK_TIGHT`（`0.008`） | `giveback` |
| 6 | 动能衰竭 | **该笔**持仓 ≥ `STALL_BARS`（`16`）根，近 16 根贴 `MA20 ± 0.5%`，均线走平，**且该笔最大浮盈 `< STALL_ABORT_RET`（`0.005`）** | `stall` |

不做融券、不反手做空。

| 步骤 | 公式 |
| :--- | :--- |
| 小时方向 | `hMA20>hMA60` 且快线非下行 |
| 15m 多头 | `MA20>MA60`、慢线非向下、收盘在 MA60 上（不要求当根 MA20 上行） |
