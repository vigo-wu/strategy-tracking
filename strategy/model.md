## 核心逻辑

分时现价相对当日 VWAP 偏离再回归：急跌止跌分档低吸，急涨缩量或回到均价附近高抛，成本止损 + 尾盘强平。做空日内情绪，不赌隔夜、不转股。

只做二级买卖。不申购、不转股、不把正股当对冲。

---

## 一、指标

### 1.1 当日 VWAP

\[
\mathrm{VWAP}_t = \frac{\sum \text{成交金额}}{\sum \text{成交量（张）}}
\]

实盘：`get_full_tick` 累计 `amount / volume`。回测：当日已收盘 1 分钟 `amount`、`volume` 累加；无 `amount` 时 \(\sum C \times V / \sum V\)，日志 `vwap_src=`。

转债成交量单位是**张**。09:30 前未就绪则不开仓。

### 1.2 分时乖离

\[
\mathrm{BIAS}_t = \frac{P_t - \mathrm{VWAP}_t}{\mathrm{VWAP}_t}
\]

config 用小数（`-0.018` = −1.8%）。

### 1.3 决策周期

主图 **1 分钟**。只在**已收盘** 1 分钟 K 上决策。沪市转债连续匹配到 **15:00**（没有深市 14:57 收盘集合）。

## 三、买入（低吸）

已收盘 1 分钟同时满足才开一档。

### 3.1 负乖离（`bias_ok`）

转债档，不用 ETF 的 −1.2%。

| 档 | `BIAS` | 本档资金 | 日志 |
| :--- | :--- | :--- | :--- |
| L1 | ≤ −1.8% | 30% | `buy_l1` |
| L2 | ≤ −2.5% 且已持 L1 | 30% | `buy_l2` |
| L3（默认关） | ≤ −3.5% | 40% | `buy_l3` |

L2/L3 须再次满足 3.2 与 3.3。

### 3.2 动量（`impulse_ok`）

看**信号根之前**的最近 **2** 根已收盘 1 分钟，满足其一即可：

- 至少 1 根阴线；或
- 窗口最高价到末收回撤 ≥ **0.5%**（`IMPULSE_SUM`）；或
- 窗口末根 `(开 − 收) / 开 ≥ 0.2%`（`LAST_DROP`）。

均价同步阴跌、BIAS 张不开则自然不买。

### 3.3 止跌（`reversal_ok`）

当前已收盘 1 分钟满足其一：收盘 > 开盘；收盘 ≥ 上一根收盘；下影占比 > **0.25**。

BIAS 已 ≤ L2（−2.5%）且**空仓**时，允许跳过止跌开 L1。**加 L2 必须止跌**，且 **现价不得低于当前持仓均价**（禁止亏损加仓）。当日若已卖出且仍有剩余仓，不再新开（`scale_out_lock`）。

### 3.4 买入拦截

| 条件 | 日志 |
| :--- | :--- |
| §2 硬拦截 / 流动性 / 价差 | `univ_skip` |
| 09:30–09:35、13:00–13:05 | `open_skip` |
| 已过 `NO_NEW_ENTRY`（14:40） | `late_skip` |
| 该档已有仓或 pending | `lot_skip` |
| 已止损或进入强平 | `risk_skip` |
| 当日已卖且仍持仓 | `scale_out_lock` |
| L2 时现价低于均价 | `l2_underwater` |

## 四、卖出

优先级：`eod_flatten` > `stop_loss` > `trail_stop` > `take_profit` > `fade_sell` > `vwap_reversion`

### 4.1 移动止盈（`trail_stop`）

合并均价浮盈达到 **+1.2%** 后，自峰值回撤 **0.5%** 则全平。用来接住「先冲到 +1.4% 再单边砸到止损」的路径（v0.8 的 02-04）。

### 4.2 成本止盈（`take_profit`）

相对该笔成本回升 **≥ 1.0%**，只平达到阈值的笔。未到 1.2% 启动带的日子仍靠这一档离场。

### 4.3 量能衰竭高抛（`fade_sell`）

1. `BIAS ≥ +0.8%`（5 分钟 p90；原 +1.5% 在持仓后 1 分钟样本为 0 次）
2. 若 BIAS 尚未到 +1.2%，还要求上一根已收盘 1 分钟量 ≤ 再上一根的 **75%**

### 4.4 回归减仓（`vwap_reversion`）

`BIAS ≥ 0`（回到均价或之上）且该笔已盈利。不再使用 0～+0.2% 窄带（1 分钟容易跳过该区间）。

### 4.5 成本硬止损（`stop_loss`）

相对持仓**合并均价** −**3.0%**，清可卖仓。

### 4.6 尾盘强平（`eod_flatten`）

沪市连续到 15:00。`FLAT_START`（**14:50**）起清仓。未平仓视为策略失败。
