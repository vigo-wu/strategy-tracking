# v0.2 回测解读与 v0.3 因子改动

对照 `回测分析报告.md`（2025-08-22～2026-08-14，513530.SH，预算 5 万，15 笔闭合，终端盈亏 **−1,193 元**）。不是网格搜参：只改报告里能对上号的结构问题。样本只有 15 笔，改完必须再回测，不能当成已验证 edge。

## 报告里的问题

1. **stall 占 11/15 笔，止盈 0 笔。** `STALL_BARS=6`（1.5 小时）等于把「缩量贴 MA20」这个买点本身当成卖点。胜率 53%，但盈亏比约 0.57（赚 1569 / 亏 2762），小赢被提前砍掉。
2. **最大亏损 −1,144 元（11/13 14:45 买 → 11/17 止损）。** 信号允许到 14:30，次根 14:45 成交，周末隔夜。T+0 挡不住隔夜。
3. **giveback 两笔都是次日早盘、约 −0.85%。** 规则是「收盘创新高后回吐 0.6%」，隔夜噪声就能触发，从未等到 1.5% 止盈。
4. **engulf 3 笔全赚（+380 / +95 / +596）；hammer 12 笔含全部大亏。** 锤子改为必须收阳，不删因子。

## v0.3 改了什么

| 因子 | v0.2 | v0.3 | 针对 |
| :--- | :--- | :--- | :--- |
| stall 根数 | 6 | 16（约 1 日） | 过早贴线出场 |
| stall 优先级 | 高于止盈 | 低于止盈/回吐 | 让盈利单跑 |
| stall 作废 | 无 | 持仓期曾 ≥0.5% 浮盈则不用 stall | 同上 |
| giveback | 任意微利即可 0.6% 回吐 | 须先达到 1.5% 止盈门槛，回吐 0.8% | 隔夜假回吐 |
| 尾盘买 | 14:30 信号 → 14:45 成交 | 去掉 14:30；14:45/15:00 成交作废 | 11/13 那笔 |
| MA 止损 | 任意 15m 收盘 | 仅 `>=10:15` | 早盘缺口误杀 |
| hammer | 可收阴 | 必须 close>=open | 假阴噪音 |

未动：小时趋势、缩量、MA 周期。h1_skip 多是过滤空头，不是亏损来源。
