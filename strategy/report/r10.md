# v0.8 冲次数（对照 v0.7）

同一区间约一年（2025-08-22～2026-08-14）、513530.SH、预算 5 万。v0.7 终端 **+7,393 元（+14.8%）**，胜率 11/14。年化 30% 大约要 **+15,000**，还差一倍。

## 30% 差在哪

不是把止盈从 1.5% 拉大。7 月多回合（约 +3,300）已经接近把那段涨幅吃完；空窗主要是 **小时趋势未向上**（11 月下旬～次年 1 月中、3 月大部分、5～6 月几乎全是 `h1_skip`）。把 `h1` 拆掉等于在下跌段做回踩，12 月 1.57→1.49 会把利润吐回去。

能加独立回合、且仍在多头里的缺口：

| 窗口 | v0.7 卡住 | 价格 |
| :--- | :--- | :--- |
| 2026-01-27～29 | `h1=True`，11:00 `vol_skip` / `touch_skip` | 1.517→1.558 |
| 2026-02-11 | `stall_cool` 禁 bounce，次日 hammer 隔夜 `stop_ma` **-441** | v0.5 同日 bounce 是 **-317** |
| 3 月若干日 | `h1=True` 但 `trend_skip`（MA60 微下行） | 震荡，预期贡献有限 |

加预算只放大金额，**不改变百分比**。14:00/14:15 不加回来（隔夜缺口）。bounce 不改成任意收阳。

## 本轮改动

| 因子 | v0.7 | v0.8 |
| :--- | :--- | :--- |
| 小时趋势 | `hMA20>hMA60` 且快线非下行 | **只要求 `hMA20>hMA60`** |
| 15m 趋势 | MA60 当根不下行 | **允许 MA60 走平/微下**（仍要 MA20>MA60、收盘在 MA60 上） |
| 触线 | 0.4% | **0.8%** |
| 缩量 | 一律 <85% 均量 | **仅 bounce** 要求 <110% 均量；hammer/engulf 不再 `vol_skip` |
| stall 当日冷却 | 禁 hammer/bounce | **去掉**（v0.7 用 -441 换了 -317） |
| 午后偏晚 / trend_break 收紧 | 保留 | 保留 |

预期：笔数应高于 14；1 月底那波有机会进场；2 月 stall 后应回到 bounce 路径。**不保证一次回到 +30%**：空窗仍由 `h1` 挡住，这是方向过滤不是漏信号。覆盖 log 后看合计盈亏，不要只看次数。
