# v0.5 增加交易次数（对照 v0.4）

v0.4 同一区间只有 **8 笔**。日志里小时趋势已经向上时，卡住开仓的主要是：`trend_skip`（回踩当根还要求 MA20 上行）、`vol_skip`（0.70 且还要小于前波上涨量）、`touch_skip`、`pattern_skip`。不是再砍过滤，而是把「回踩」定义对齐到实际 K 线。

**不改**：14:00/14:15 禁开、14:15 及之后成交作废、stall/止盈/回吐阈值。加次数不靠把隔夜亏损窗口加回来。

| 因子 | v0.4 | v0.5 |
| :--- | :--- | :--- |
| 15m 趋势 | MA20 当根必须上行 | **允许走平**（回踩常态） |
| 小时趋势 | hMA20 必须上行 | **允许走平** |
| 缩量 | <70% 均量 **且** <70% 前波上涨量 | **仅 <85% 均量** |
| 触线 | 0.2% | **0.4%** |
| 锤子 | 下影 2×实体、实体≤40% | **1.5×、≤50%** |
| 形态 | hammer / engulf | **+ bounce（回踩收阳）** |
| 上午窗 | 10:15 起 | **含 10:00**（次根 10:15） |

预期：笔数应明显高于 8；7 月三笔止盈应仍在；可能重新出现一些隔夜 `stop_ma`（13:30 一类）。覆盖 log 后再看盈亏是否同步变大，而不是只看次数。
