# v1.0 止盈改跟踪（对照 v0.9）

v0.9 同一区间 **+7,517（+15.0%）**。7 笔 `take_profit` 都是「浮盈刚过 1.5% 且离开 MA20」。离开均线是回踩成功、趋势续上，不是该出的点。7 月被切成 6 段（合计约 +3,300）；若 7/10 一笔拿到 7/29 附近，大约是 +8%～9%，比切段多约 1,300。10～11 月同理。

入口过滤不动（v0.8 已证伪放宽）。只改出场。

| 因子 | v0.9 | v1.0 |
| :--- | :--- | :--- |
| 离开均线硬止盈 | 1.5% 且离 MA20 0.8% 即出 | **默认关**（面板可打开） |
| 回吐启动 | 收盘最高 +1.5% | 同 |
| 回吐宽度 | 0.8% | **1.2%**（刚启动时普通回踩不洗出） |
| 大浮盈收紧 | 无 | 最高浮盈 **≥4%** 后回吐改 0.8% |
| stall / stop_ma / trend_break | 同 | 同（没启动的单仍砍） |

预期：笔数应少于 14（7 月/11 月少几次进出）；单笔持仓变长；合计应高于 +7,517 才算这刀有效。**不保证 30%**：即便两段主升浪都拿满，粗算大约再加 2,000～4,000，仍可能停在 20% 上下。覆盖 log 后看笔数和合计，不要只看单笔变大。
